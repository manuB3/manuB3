## Quand les dirigeants m'appellent

- Un projet informatique dérape : délais, budget, prestataire qui ne répond plus.
- Un choix tech est à arbitrer sans avoir les clés pour juger : logiciel métier, devis, refonte.
- Le système d'information freine la croissance : tableurs à côté du logiciel, recrutements pour compenser, abonnements que plus personne ne sait justifier.
